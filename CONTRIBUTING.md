# Contributing

Thanks for helping grow this list.

## What belongs here
- Prompts for **remaking ads that already work** (hook / pacing / proof / CTA)
- AI video + stills workflows that keep **your product** in frame
- Public demos with a clear source link (X, GitHub, blog)

## What does not
- Studio / cinema vibe with no ad remake angle
- Stolen prompts without attribution
- Rehosted media you do not have rights to

## How to add
1. Open a PR that adds one entry under **Latest prompts** in `README.md`
2. Include: title, short note, prompt in a fenced `text` block, source link
3. Optional: EasyVeo CTA only if the workflow maps to decode → stills → remake

## Style
- Short, operator-plain English
- Tagline for EasyVeo: **Remake the winner. Keep your product.**
